#   ROUTER <id>
#   LINK <a> <b> <cost>
#
# Topology sketch:
#
#       A ----1---- B ----1---- C
#       |           |           |
#       4           2           3
#       |           |           |
#       F ----1---- E ----1---- D
#
# Alternate path A↔F↔E↔D↔C exists when A–B or B–C fails.

ROUTER D
ROUTER E
ROUTER F
